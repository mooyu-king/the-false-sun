About Cobb Can Move

Browser Play Overview

This Cobb Can Move page is built to keep browser play straightforward. You can launch the iframe quickly, switch to fullscreen from the shared toolbar, and keep short support notes on the same page without leaving the game frame.

Play Cobb Can Move In a Dedicated Frame

This route follows the shared in-site game page template, so Cobb Can Move gets the same top bar, footer, iframe area, and expandable support sections as the rest of the project.

The goal is consistency: when more games are added, each one can keep the same shell UI while changing only the iframe source and the descriptive content blocks.

Fullscreen, Loading, and Session Notes

If you want the cleanest experience, start Cobb Can Move in the embedded frame and then use the fullscreen button in the toolbar. That keeps the page structure simple while still giving the game more room when you need it.

If the iframe appears blank or paused, wait a moment for the remote game host to respond, click once inside the player, and then refresh the page if necessary before assuming the embed failed.

Placeholder Media Can Be Replaced Later

This page currently uses local placeholder artwork because only the iframe source was provided. When official cover art, screenshots, or trailer links are available, those assets can be swapped in without changing the page structure.

That makes this page a practical example of the project's new workflow: keep a stable template in `tmple/`, copy it into `src/app`, and then refine each new route as real assets become available.
