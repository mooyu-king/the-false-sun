# The False Sun

The False Sun is a browser horror visual novel set around a farm that should feel familiar, calm, and safe. Warm daylight, soft grass, and a welcoming face create the first impression, but that comfort slowly bends into unease as memory gaps widen and ordinary details stop feeling trustworthy.

This static site build is published for https://the-false-sun.org/ and keeps the game frame, story overview, videos, FAQ help, blog content, and legal pages together in one place. The goal is to make The False Sun easy to launch, easy to revisit, and easy to share.

## Story Overview

The False Sun opens on your grandfather's farm, where the day is bright and a familiar smile should be reassuring. Instead, the scene grows stranger the longer you stay with it. The story leans on subtle pressure rather than loud shocks, turning warmth, routine, and memory into the heart of its horror.

The site presents The False Sun as a story-rich browser experience. Players can start the game, watch embedded videos, read spoiler-light notes, and browse support pages without leaving the same domain. The tone is built around slow-burn psychological tension, replay value, and the unsettling contrast between kindness and control.
